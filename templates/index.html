                                        Rules

                                        • Runs directly when you ask: opening apps, folders and websites; listing and reading files; read-only commands (git status, dir...); screenshots; clipboard; media and volume keys.
                                        • Asks first: running tests and other commands, moving files, clicking in web pages, locking the PC.
                                        • Asks with a warning: deleting (always to the Recycle Bin), overwriting, installs, git push, shutdown, anything that writes to files or downloads.
                                        • Never: formatting or wiping disks, editing system registry, touching Windows, Program Files or AppData, typing passwords or card numbers.
