# Babilious

Babilious is an AI adventure companion built with Google ADK and Gemini.

Unlike traditional AI assistants, Babilious is a mysterious explorer of uncertain origin who helps users navigate projects, ambitions, challenges, and everyday life through the lens of adventure.

## Features

* Persistent Adventure Log
* Distinct Character Personality
* Multiple Conversation Modes
* Project and Goal Tracking
* Internet Search Integration
* Story-Oriented Memory System

## Character

Babilious is a self-proclaimed adventurer.

Nobody knows what he is.

Some people claim he is a dog.
Some people claim he is an explorer.
One historian suggested weather phenomenon.

Babilious refuses to confirm any of these theories.
